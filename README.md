<h1>🔎 GitHub Repository Finder</h1>

Um aplicativo simples feito para facilitar a busca por repositórios do GitHub usando apenas o nome ou a extensão de um arquivo.

A ideia é ser algo pequeno, simples e direto ao ponto: você informa o que está procurando e o app busca repositórios que possuem aquele arquivo.

---

✨ O que ele faz?

Com ele, você pode pesquisar por:

- 📄 Nome de arquivo
- 🧩 Extensão de arquivo
- 📦 Repositórios do GitHub

Por exemplo, você pode pesquisar:

README.md

ou:

.gd

E o aplicativo irá buscar repositórios relacionados à pesquisa.

---

🔐 Token do GitHub

Para realizar as requisições à API do GitHub, o aplicativo pede um Personal Access Token (PAT).

«Importante: o token é utilizado apenas para realizar as requisições e não é salvo pelo aplicativo.»

Mesmo assim, nunca compartilhe seu token ou coloque ele diretamente no código-fonte.

---

🚀 Como usar

1. Abra o aplicativo
2. Informe seu GitHub PAT
3. Digite o nome ou extensão do arquivo que deseja encontrar
4. Faça a pesquisa
5. Veja os repositórios encontrados

É basicamente isso. 😄

📌 Sobre o projeto

Este é um projeto simples e experimental, criado para facilitar a descoberta de repositórios do GitHub através de arquivos.

A intenção não é criar uma ferramenta gigantesca, mas sim algo prático e fácil de usar.

«💡 Simples, direto e útil.»

---

⚠️ Observação

Os resultados da pesquisa dependem da API do GitHub, incluindo suas limitações e regras de pesquisa.
